# pagina-monarq
Landing Page de monarq

## Experiencias de clientes

La interfaz de experiencias valida los datos en el navegador, pero no almacena ni publica envíos. Para habilitarla en producción se necesita un endpoint autenticado que valide el formulario, almacenamiento privado de imágenes, una base de datos con estado `pending`, y una herramienta de administración para aprobar o rechazar cada envío antes de mostrarlo en la galería pública. No se deben incluir credenciales de almacenamiento en el cliente.
